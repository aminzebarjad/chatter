## 🚀 شروع سریع

برای اجرای چت‌روم روی مخزن گیت‌هاب خود، کافیست این مراحل را دنبال کنی:

### ۱. مخزن خود را ایجاد کن

یک مخزن جدید (مثلاً `chatter`) در گیت‌هاب بساز.  
سپس داخل آن سه فایل اصلی را قرار بده:

- `index.html`
- `css/style.css`
- `js/script.js`
- `chat.json` (خالی یا شامل پیام پیش‌فرض)
- `password.json` (شامل رمز اولیه)

### ۲. فایل‌های اولیه را مقداردهی کن

**`chat.json`** (نمونه):
```json
[]
```

**`password.json`** (رمز اولیه):
```json
{
  "password": "1234"
}
```

### ۳. تنظیمات پروژه را ویرایش کن

در فایل `js/script.js` خطوط زیر را مطابق مخزن خودت تغییر بده:

```javascript
const REPO_OWNER = 'your-username';     // اکانت گیت‌هاب شما
const REPO_NAME = 'chatter';            // نام مخزن
const ADMIN_USERNAME = 'your-username'; // فقط این کاربر ادمین است
// رمز اتاق دیگر در کد ثابت نیست، بلکه از password.json خوانده می‌شود
```

> توجه: رمز اتاق دیگر در کد ثابت نیست، بلکه از فایل `password.json` خوانده می‌شود. تغییر آن فقط توسط ادمین ممکن است.

### ۴. فعال‌سازی گیت‌هاب پیج

به تنظیمات مخزن برو (`Settings > Pages`) و شاخه `main` را به عنوان منبع انتخاب کن.  
چت‌روم در آدرس زیر در دسترس خواهد بود:

```
https://your-username.github.io/chatter/
```

### ۵. توکن دسترسی بساز

هر کاربر برای ارسال و مشاهده پیام‌ها به یک **توکن شخصی گیت‌هاب** نیاز دارد.  
راهنمای ساخت توکن داخل خود برنامه موجود است (بخش «راهنمای ساختن توکن»).  
حداقل اسکوپ‌های مورد نیاز: `repo` و `user`.

## 📁 ساختار پروژه

```
chatter/
├── index.html
├── chat.json
├── password.json
├── css/
│   └── style.css
├── js/
│   └── script.js
└── README.md
```

| فایل | نقش |
|------|------|
| `index.html` | ساختار اصلی صفحات (رمز، توکن، چت) و مودال تغییر رمز |
| `css/style.css` | استایل مدرن، تم دارک، ریسپانسیو، انیمیشن‌ها و تولتیپ اختصاصی |
| `js/script.js` | منطق کامل برنامه: ارتباط با گیت‌هاب API، مدیریت پیام‌ها، رمز، ادمین، اموجی و ... |
| `chat.json` | دیتابیس ساده شامل آرایه‌ای از پیام‌ها |
| `password.json` | ذخیره‌ی رمز فعلی چت‌روم (توسط ادمین قابل تغییر) |

## ⚙️ پیکربندی پیشرفته

### تغییر ادمین

فقط کاربری که `ADMIN_USERNAME` برابر با نام کاربری گیت‌هاب او باشد، دکمه‌های **پاک کردن چت** و **تغییر رمز** را می‌بیند.

### تغییر بازه‌ی همگام‌سازی

در `script.js` خط مربوط به `setInterval` را تغییر بده:

```javascript
refreshInterval = setInterval(loadMessages, 4000);  // ۴ ثانیه (پیش‌فرض)
```

### افزودن استیکرهای جدید

آرایه `stickers` را در `script.js` ویرایش کن:

```javascript
const stickers = ['😍', '👍', '🎉', '💔', '🤣', '🔥', '😎', '❤️', '🥲', '⭐'];
```

## 🔒 امنیت

- **رمز اتاق** در فایل عمومی `password.json` ذخیره می‌شود (برای خواندن توسط صفحه ورود). اما *تغییر* آن فقط با توکن گیت‌هاب **ادمین** امکان‌پذیر است.
- **توکن شخصی** هر کاربر در `localStorage` مرورگر خودش ذخیره می‌شود و هرگز به سرور یا شخص ثالثی ارسال نمی‌شود.
- کلیه درخواست‌ها به گیت‌هاب API از طریق HTTPS و با احراز هویت توکن انجام می‌شود.
- پیام‌ها به صورت خودکار با `escapeHtml` از XSS محافظت می‌شوند.
- ادمین نمی‌تواند رمز جدید را بدون تأیید رمز فعلی تغییر دهد.
