برای چت کردن، باید توکن شخصی خودت رو وارد کنی.

📌 قدم‌های ساختن توکن

  1. به آدرس github.com/settings/tokens برو.
  2. روی Generate new token (classic) کلیک کن.
  3. یک اسم براش بذار (مثلاً ChatRoom).
  4. در بخش Select scopes، تیک repo و user رو بزن.
  5. پایین صفحه رو بزن Generate token.
  6. ⚠️ توکن رو کپی کن و همین‌جا وارد کن. (فقط همین یک‌بار نشون داده می‌شه).

🔒 این توکن فقط توی مرورگر خودت ذخیره می‌شه و جایی ارسال نمی‌شه.
